    알고리즘 문제해결 블로그 완전 자동화

    1. 자동 수정기록 저장

      코드를 수정하면 자동으로 로컬에 수정 기록을 저장합니다.

    2. 자동 메모 생성

      로그인하면 코드와 변경 기록을 AI에 보내 메모를 만듭니다. 설정에서 끌 수 있어요.

    3. 블로그 생성&편집

      VSCode 내에서 블로그를 즉시 생성&편집할 수 있습니다.

    4. 블로그 내보내기

      블로그를 원클릭으로 내보냅니다. (블로그 API or 브라우저 확장 이용)

    코드와 개인정보
